下载、解压、双击启动，再粘贴 Bangumi 个人令牌即可使用。不需要安装 Node.js、Git 或运行命令，也不必创建开发者应用。

## 选择下载包

| 电脑 | 文件 |
| --- | --- |
| Windows 10 / 11，Intel 或 AMD 处理器 | `bangumi-watch-planner-v1.4.0-windows-x64.zip` |
| Mac，Apple 芯片（M 系列） | `bangumi-watch-planner-v1.4.0-macos-arm64.zip` |
| Mac，Intel 处理器 | `bangumi-watch-planner-v1.4.0-macos-x64.zip` |

不要选择 GitHub 自动生成的 `Source code`。

Mac 需要 macOS 13.5 或更高版本。

## 开始使用

1. 解压安装包。Mac 把 `.app` 放入“应用程序”后双击；Windows 双击 `Start Bangumi Watch Planner.cmd`。
2. 网页自动打开，点击“获取个人令牌”，在 Bangumi 官方页面登录并创建令牌。
3. 粘贴令牌并连接，应用会自动同步。以后双击启动即可。

原来的 OAuth 登录仍保留在高级选项中。个人令牌到期或被撤销后，需要重新生成并粘贴。

## 本版更新

- 补番改为自由片库、自动最近观看和按需挑选，取消每日补番任务与完成期限。
- 保留原来的分集格点击方式：点未看正片标记到该集，点已看只取消该集，特别篇单独切换；未看白/透明、已看粉色。
- 保留粉色和动漫感，统一页面排版、卡片和按钮对齐，分集原位展开。
- 最近观看使用真实分集记录时间，不用同步或收藏更新时间推测。
- 封面增加本地缓存、超时切换和联网重试。
- 修复跨页刷新、请求竞态、授权状态与放送显示问题。

Mac 数据保存在 `~/Library/Application Support/BangumiWatchPlanner`，升级时替换 `.app` 即可。旧版源码部署仍可保留原目录使用，升级前请保留 `data/` 与配置。

安装包尚未经过商业代码签名或 Apple 公证，首次打开可能出现系统来源确认。后台提醒需要电脑保持开机且服务运行。发布附件包含 `SHA256SUMS.txt`，可用于核对下载文件。
